# TweetAPI

Independent third-party REST API for public Twitter/X data, built for developers, researchers, startups, agencies, and analytics teams. Offers user profiles, tweets, search, lists, communities, Spaces, posting/engagement, and DMs, plus a hosted MCP server and llms.txt for agent access. Not affiliated with X Corp.

- **Provider:** https://tweetapi.com
- **Documentation:** https://tweetapi.com/docs/getting-started/overview
- **Base URL:** https://api.tweetapi.com/tw-v2
- **Tags:** twitter, x, social-media, social-data, search, analytics, research, developer-tools, mcp, agent-native, llms-txt, rest-api

## APIs

- **TweetAPI tw-v2 REST API** — REST API for public Twitter/X data with X-API-Key auth, JSON responses, and 76 documented endpoints across users, tweets, posting, interactions, lists, profiles, communities, Spaces, search, auth, X Chat, and legacy DMs. (`https://api.tweetapi.com/tw-v2`)
- **TweetAPI Hosted MCP Server** — Hosted remote HTTP MCP server providing current TweetAPI docs and read-only live public-data tools. Uses OAuth via dashboard authorization (tweetapi:read); does not expose posting, engagement, account-secret, or DM operations. Documented for Codex, Claude Code, and Cursor. (`https://mcp.tweetapi.com/mcp`)

> REST API (base https://api.tweetapi.com/tw-v2, X-API-Key auth, JSON, 76 endpoints), a hosted MCP server at https://mcp.tweetapi.com/mcp (OAuth/dashboard auth, read-only), and an llms.txt at https://tweetapi.com/llms.txt are all publicly confirmed. A machine-readable plain-text endpoint catalog is at https://tweetapi.com/ai-docs-v2.txt and provider metadata at https://tweetapi.com/apis.json, but no formal API contract (OpenAPI/AsyncAPI/GraphQL/Postman) is public — the spec lives in a private repo. No packaged agent skills found. Official Python (github.com/tweetapi/python, pip install tweetapi) and Node.js/TypeScript (github.com/tweetapi/node, npm install tweetapi-node) SDKs exist. Access requires a TweetAPI account/API key; a no-card free tier is available.
