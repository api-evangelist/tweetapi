# TweetAPI - Third-Party Twitter Data API

Last updated: 2026-09-25

TweetAPI is an independent third-party API for public Twitter data. It is built
for developers, researchers, startups, agencies, and analytics teams that need
documented API access without creating an X developer app for the TweetAPI flow.

TweetAPI is not affiliated with, endorsed by, or sponsored by X Corp.

## Public Pricing

- Free: $0 with a one-time 100-unit trial, enough for 100 normal one-unit
  requests, at 10 requests per minute. No credit card required.
- Pro: $17 per month for 100,000 API units at 60 requests per minute.
- Ultra: $57 per month for 500,000 API units at 120 requests per minute.
- Mega: $197 per month for 2,000,000 API units at 180 requests per minute.

Plan allowances count API units, not returned posts. Most metered calls use one
unit; `/tw-v2/xchat/send` uses 10 and `/tw-v2/auth/login` uses 500. Rate limits
count HTTP requests per minute, not units. Public paid plans include all public
endpoint categories. Private, legacy, or custom plans can differ.

## Pay as You Go

- Prepaid PAYG starts at $5 USD for 10,000 API units. No subscription is
  required. Top-ups are one-time purchases and do not renew automatically.
- Available trial or subscription allowance is used first, then valid PAYG
  units. Standalone PAYG allows 60 requests per minute; an active plan keeps
  its higher rate limit. Canceling a subscription leaves valid wallet units
  available until their expiry.
- PAYG units expire 365 days after successful payment settlement. Applying a
  top-up extends a still-valid wallet to the later of its existing expiry or
  the new settlement date plus 365 days. Expired units are not restored.
- Full rules: https://tweetapi.com/terms#payg

## Payment Methods

- Credit and debit cards through Stripe. Card subscriptions auto-renew.
- Cryptocurrency through NOWPayments. Crypto subscriptions use manual renewal.

## API Access

- Base API URL: https://api.tweetapi.com/tw-v2
- Authentication: `X-API-Key` request header. Posting, engagement, profile,
  DM, and X Chat operations can require additional account authorization;
  check each endpoint's required fields.
- Response format: JSON.
- Pagination: cursor-based on endpoints that return paginated collections.
- A `429` can indicate an inactive subscription, exhausted allowance and PAYG
  balance, or a per-minute limit. These responses do not include `Retry-After`
  or `X-RateLimit-*` headers. Inspect the error; use bounded backoff for
  per-minute limits.
- A `503` response can include `Retry-After`; follow it when present and use
  bounded retries. Before retrying an action after an uncertain outcome, check
  whether it completed.

## Monitoring and Alerts

- TweetAPI returns JSON when a customer calls a REST endpoint. The customer
  operates scheduling, pagination, deduplication, storage, and delivery.
- TweetNotify is a separate product for managed public-account and keyword
  monitoring. It can deliver detected posts through Discord, Telegram, or
  signed HTTPS webhooks, and it has separate access and pricing.
- Comparison guide:
  https://tweetapi.com/docs/getting-started/real-time-monitoring

## Hosted MCP for AI Agents

- Public product page: https://tweetapi.com/mcp
- Hosted remote HTTP MCP URL: https://mcp.tweetapi.com/mcp
- Setup guide: https://tweetapi.com/docs/getting-started/agents
- Existing-user dashboard flow: https://tweetapi.com/dashboard/mcp

Requirements:

- A TweetAPI account.
- An active TweetAPI API key selected during dashboard authorization.
- An agent client with remote HTTP MCP and OAuth support.

Boundaries:

- Hosted MCP provides current TweetAPI docs and read-only live public-data tools.
- Live MCP calls consume the normal quota of the selected TweetAPI API key.
- Dashboard authorization keeps the API key behind the TweetAPI OAuth boundary.
- Do not paste TweetAPI API keys, X account tokens, proxy credentials, or private
  message content into agent prompts.
- Use normal server-side REST or SDK code when integrating TweetAPI into an
  application, background job, or data pipeline.

## Free Developer Tools

- Timestamp converter: https://tweetapi.com/tools/twitter-timestamp-converter
  Decodes modern post IDs or status URLs in the browser, identifies legacy IDs
  without guessing a date, generates date boundary IDs, and converts up to 100
  IDs or URLs to a local CSV. Conversion needs no signup or TweetAPI request.
- Advanced search builder: https://tweetapi.com/tools/twitter-advanced-search
  Manual mode builds and validates a query in the browser without running a
  search. An authenticated Playground request uses API allowance. Optional AI
  interpretation sends a description to OpenAI only when requested.
- User ID finder: https://tweetapi.com/tools/twitter-id-finder
  Retrieves one public account at a time, from username or profile URL to user
  ID or from user ID to current username. Successful results may be cached for
  up to five minutes. No user signup is needed; usage limits apply.
