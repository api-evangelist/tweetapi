================================================
QUICK REFERENCE
================================================

Base URL: https://api.tweetapi.com/tw-v2
Authentication: All requests require X-API-Key header
Plan Limits: Free trial accounts initialize at 10 requests/minute. Paid, private, legacy, and custom limits are subscription-specific. A 429 response can mean that the request allowance or per-minute limit was exceeded; inspect its message before retrying. TweetAPI's tw-v2 endpoints do not currently return Retry-After or X-RateLimit-* headers.

================================================
AUTHENTICATION
================================================

All API requests require an API key in the X-API-Key header:

curl -H "X-API-Key: YOUR_API_KEY" https://api.tweetapi.com/tw-v2/[endpoint]

For authenticated user actions (posting, liking, following, DMs), you also need:
- authToken: Account authentication token (auth_token cookie value)
- ct0: CSRF token (ct0 cookie value) - required for X Chat/DM endpoints
- proxy (optional): Proxy in format 'host:port@user:pass'

================================================
SHARED TWEET OBJECT NOTES
================================================

Endpoints that return normalized Tweet objects may include `reactionContext`.
Reaction posts are returned as quote tweets (`type: "quote"`) with `reactionContext.isReaction === true`.
Normal tweets and normal quote tweets return `reactionContext: null`.

Shape:
{
  "reactionContext": {
    "isReaction": true,
    "targetTweetId": "2000000000000000001",
    "targetTweetUrl": "https://x.com/sample_user_00001/status/2000000000000000001",
    "targetAuthor": {
      "id": "1000000000000000001",
      "username": "sample_user_00001",
      "name": "Sample User 00001",
      "avatar": "https://example.com/images/sample-avatar-00001.jpg",
      "isBlueVerified": true
    }
  }
}

If upstream marks a tweet as a reaction but target metadata is unavailable, `targetTweetId`, `targetTweetUrl`, and `targetAuthor` may be null.

### POST /tw-v2/interaction/create-post

**Description:**
Post a new tweet to the platform. Supports text content up to 280 characters for non-premium users, or 25,000 characters for premium users.

**Request Body:**
- authToken (string, required): Account authentication token (auth_token cookie value)
- text (string, required): The text content of the tweet (max 280 characters for non-premium, 25,000 for premium)
- proxy (string, required): Proxy in format 'hostname:port@username:password' (required for better success rates)
- disableLinkPreview (boolean, optional): When true, disables link preview cards for tweets containing URLs (defaults to false)
- replyOption (object, optional): Optional reply controls. Use {"mode":"everyone"}, {"mode":"accounts_you_follow"}, {"mode":"accounts_you_follow_and_followed"}, {"mode":"mentioned_accounts"}, {"mode":"verified_accounts"}, or {"mode":"regions","regions":["NAM","EUR"]}. Region buckets: NAM, EAS, AFR, SEA, SAM, EUR, AUS, SAS, WES, CAS.

**Example:**
```bash
curl -X POST "https://api.tweetapi.com/tw-v2/interaction/create-post" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "authToken": "YOUR_AUTH_TOKEN",
  "text": "Hello, world!",
  "replyOption": {"mode":"mentioned_accounts"}
}'
```

ADDITIONAL INFORMATION
================================================================================

**Response Format:**
- All endpoints return JSON responses
- Success responses are wrapped in a "data" object
- Error responses include "error" object with code and message

**Data Types:**
- Timestamps are in ISO 8601 format (e.g., "2025-10-05T14:30:00.000Z")
- IDs are strings (snowflake IDs, e.g., "1234567890")
- Cursors are opaque strings used for pagination

**Pagination:**
- Many endpoints support cursor-based pagination
- Include "cursor" parameter from previous response to get next page
- When cursor is absent/empty, you've reached the end

**Rate Limiting:**
- Rate limits are per API key and per minute
- HTTP 429 can indicate request-allowance exhaustion or a per-minute limit; inspect the error message before retrying
- TweetAPI's tw-v2 endpoints do not currently return Retry-After or X-RateLimit-* headers
- Use bounded backoff and lower concurrency for transient per-minute limits
